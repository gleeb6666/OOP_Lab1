# Як підключити Google Drive (ЛР 1*)

Програмі потрібен файл `client_secret.json` — «ключ» OAuth-клієнта Google. Його створюють у власному акаунті Google безкоштовно, банківська картка не потрібна. Це займає 5–10 хвилин.

> Назви пунктів у Google Cloud Console іноді змінюються. Якщо щось виглядає інакше — шукайте за змістом: «Google Auth Platform», «OAuth consent screen», «Clients / Credentials».

## 1. Створити проєкт

1. Відкрийте https://console.cloud.google.com/ і увійдіть своїм акаунтом Google.
2. Угорі ліворуч — список проєктів → **New project** (Новий проєкт).
3. Назва, наприклад `OOP LR1` → **Create**. Дочекайтеся створення та оберіть цей проєкт у списку.

## 2. Увімкнути Google Drive API

1. Меню ☰ → **APIs & Services → Library** (Бібліотека).
2. Знайдіть **Google Drive API** → відкрийте → **Enable** (Увімкнути).

## 3. Налаштувати екран згоди

1. Меню ☰ → **APIs & Services → OAuth consent screen** (відкриється *Google Auth Platform*) → **Get started**.
2. **App information**: назва застосунку `Електронна таблиця`, support email — ваша пошта → Next.
3. **Audience**: оберіть **External** → Next.
4. **Contact information**: ваша пошта → Next → погодьтеся з умовами → **Create**.
5. Ліворуч **Audience** → блок **Test users** → **Add users** → впишіть свій Gmail → Save.
   *Без цього кроку Google не пустить вас у застосунок.*

## 4. Створити OAuth-клієнт і завантажити ключ

1. Ліворуч **Clients** → **Create client**.
2. **Application type**: **Desktop app**. Назва — будь-яка, наприклад `MAUI LR1` → **Create**.
3. У вікні, що з'явиться, натисніть **Download JSON**.
4. Перейменуйте завантажений файл (`client_secret_xxxx.json`) на **`client_secret.json`**.
5. Покладіть його в папку проєкту:
   ```
   MyExcelMAUIApp\Resources\Raw\client_secret.json
   ```
6. Перезберіть проєкт (у Visual Studio: «Сборка» → «Пересобрать решение» / Build → Rebuild Solution).

## 5. Перший запуск

1. Натисніть **«Зберегти в Google Drive»** або **«Відкрити з Google Drive»**.
2. Відкриється браузер із входом у Google. Увійдіть тим акаунтом, який додали в *Test users*.
3. Google попередить: «Google hasn't verified this app» (застосунок не перевірено) — для навчального проєкту це нормально: **Continue** (Продовжити).
4. Дозвольте доступ. Вкладку браузера можна закрити й повернутися до програми.

Далі вхід запам'ятовується (токен зберігається в `%LOCALAPPDATA%` у папці програми). Поки застосунок у режимі тестування, Google просить увійти знову приблизно раз на 7 днів.

## Що програма може робити на вашому Google Drive

Використовується доступ **`drive.file`**: програма бачить і змінює **лише файли, які сама створила**. Решта вмісту диска їй недоступна. Таблиці зберігаються в корінь «Мій диск» як `.json`-файли.

## Безпека

`client_secret.json` — секрет вашого проєкту Google. **Не викладайте його в публічний репозиторій** (у `.gitignore` він уже виключений) і не надсилайте іншим. Кожен, хто запускає проєкт, створює власний ключ за цією інструкцією.

## Якщо щось не працює

| Повідомлення | Що робити |
|---|---|
| «Не знайдено файл client_secret.json…» | Перевірте назву та папку з кроку 4.5, перезберіть проєкт |
| «Error 403: access_denied» у браузері | Вашу пошту не додано в *Test users* (крок 3.5) |
| «Google не надав доступ…» | Увійдіть знову; якщо повторюється — створіть ключ заново (крок 4) |
| «Операцію… скасовано або перевищено час очікування» | Вхід у браузері не завершено за 5 хвилин — повторіть |
