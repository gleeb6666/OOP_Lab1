# Електронна таблиця (ЛР №1 і №1*, ООП)

Лабораторна робота №1 «Розробка програми для роботи з електронними таблицями (аналіз та обчислення виразів)» і №1* «…що включає роботу з Google Drive». **Варіант 12.**

Виконав: Максимов Гліб Максимович, група К-28.

Застосунок на **.NET MAUI** для Windows: таблиця, клітинки якої містять арифметичні вирази з цілими числами довільної довжини, дужками та посиланнями на інші клітинки.

## Можливості

- **Два етапи обробки виразу:** синтаксична перевірка з локалізацією помилки (позиція та пояснення) і обчислення значення.
- **Режими відображення ВИРАЗ / ЗНАЧЕННЯ.**
- **Рядок формул** для виділеної клітинки та рядок стану зі значенням або описом помилки.
- Посилання на клітинки (`A1`, `AB12`), автоматичний перерахунок залежних клітинок, виявлення **циклічних посилань**.
- Додавання та видалення рядків і стовпчиків (з попередженням, якщо на них посилаються формули).
- **Збереження та читання** таблиць у JSON-файлах на комп'ютері.
- **Google Drive** (ЛР 1\*): збереження та відкриття таблиць через Google Drive API v3 з входом OAuth 2.0.
- Питання про незбережені зміни під час відкриття іншої таблиці та виходу.
- Україномовний інтерфейс і довідка.

## Операції варіанта 12 (набори 1, 4, 5, 7)

| Операція | Опис | Приклад |
|---|---|---|
| `+ - * /` | бінарні; ділення цілочисельне | `7/2` → `3` |
| `^` | піднесення до степеня, правоасоціативне | `2^3^2` → `512` |
| `inc(x)`, `dec(x)` | x+1 і x−1 | `inc(dec(5))` → `5` |
| `mmax(x1,…,xN)`, `mmin(x1,…,xN)` | найбільше / найменше, N ≥ 1 | `mmax(1, A1, 3)` |

Унарного мінуса у варіанті немає: від'ємне число записується як `0-5`. Порожня клітинка дорівнює 0.

Коди помилок у клітинках: `#SYNTAX!` — синтаксична помилка, `#DIV/0!` — ділення на нуль, `#NUM!` — некоректний степінь, `#REF!` — посилання за межі таблиці, `#CYCLE!` — циклічне посилання.

### Граматика (БНФ)

```
expr    ::= term   { ("+" | "-") term }
term    ::= power  { ("*" | "/") power }
power   ::= primary [ "^" power ]
primary ::= NUMBER | CELL | "(" expr ")" | func
func    ::= ("inc" | "dec") "(" expr ")"
          | ("mmax" | "mmin") "(" expr { "," expr } ")"
NUMBER  ::= digit { digit }
CELL    ::= letter { letter } digit { digit }
```

Розбір виконується методом рекурсивного спуску, обчислення — над деревом виразу на `System.Numerics.BigInteger`.

## Запуск

**Потрібно:** Windows 10/11, Visual Studio 2022 з навантаженням **«.NET Multi-platform App UI development»** (.NET 9 SDK).

1. Відкрити `MyExcelMAUIApp.sln` у Visual Studio.
2. Зробити `MyExcelMAUIApp` стартовим проєктом, обрати ціль **Windows Machine**.
3. Запустити (F5).

Приклад таблиці з усіма операціями та видами помилок: [`Examples/demo_variant12.json`](Examples/demo_variant12.json) — відкрити кнопкою «Прочитати».

Для роботи з Google Drive потрібен власний ключ `client_secret.json` — див. [GOOGLE_DRIVE_SETUP.md](GOOGLE_DRIVE_SETUP.md). Без ключа програма працює, лише кнопки Google Drive показують повідомлення про відсутній ключ.
